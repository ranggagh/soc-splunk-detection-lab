\# SQL Injection Detection



This scenario focuses on detecting SQL injection attempts against a web application using Splunk SIEM.



\## Status



🚧 Planned



\## Objectives



\- Simulate SQL injection attempts in a controlled laboratory environment.

\- Generate web/application logs.

\- Forward logs to Splunk.

\- Create SPL queries for SQL injection detection.

\- Identify suspicious requests and attacker source IP addresses.



\## Planned Detection



\- SQL injection payloads

\- Suspicious URL parameters

\- SQL-related keywords

\- Abnormal HTTP requests

\- Attacker source IP addresses



\## Tools



\- Ubuntu

\- Splunk

\- Splunk Universal Forwarder

\- Web Application

\- SPL
