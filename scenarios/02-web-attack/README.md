\# Web Attack Detection



This scenario focuses on detecting suspicious web attack activities using Splunk SIEM.



\## Status



🚧 Planned



\## Objectives



\- Simulate web attack activity in a controlled laboratory environment.

\- Generate and collect web server logs.

\- Forward logs to Splunk.

\- Create SPL queries for detection.

\- Identify suspicious source IP addresses and HTTP requests.



\## Planned Detection



\- Suspicious HTTP requests

\- Abnormal request patterns

\- Multiple requests from a single source IP

\- Potential web attack indicators



\## Tools



\- Ubuntu

\- Splunk

\- Splunk Universal Forwarder

\- Web Server

\- SPL
